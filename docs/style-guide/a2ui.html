A2UI Component Guide

Live examples of every component registered in our chat artifact renderer. These are the components supported by this checkout, not the full upstream Coworker catalog. Each preview uses the real renderer and stylesheets, isolated in a shadow root just like the chat UI. Consumer-owned icon artwork is loaded from da.live.

Expand an example's JSON to copy its flat A2UI records. Child IDs compose the tree from root. Put the array in your artifact's components field; it is not a complete harness tool invocation. See the chat documentation for action handling.
