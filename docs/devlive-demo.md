# Devlive demo

The `devlive` branch carries the quick-edit HTML/block drop and relayed image-drop
support from `feat/quick-edit-table-drop`. Its matching `adobe/da-live` branch
combines `qedrop` with the `blocktab` configuration sidebar.

Use both `nx=devlive` (the host's Nexter modules) and `quick-edit=devlive` (the
plugin loaded by the page preview):

https://devlive--da-live--adobe.aem.live/canvas?nx=devlive&quick-edit=devlive#/exp-workspace/frescopa/drafts/hhertach/test

See `adobe/da-live`'s `docs/devlive-demo.md` for the demo flow and prerequisites.
