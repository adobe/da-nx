# Tool Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Extract one card into shared `<nx-action-card>`, use it in `cards` and `site-apps`.

**Architecture:** Lit component with shadow styles + shared search helper; blocks map data → properties.

**Tech Stack:** Lit (`da-lit`), WTR + chai + sinon.

**Spec:** `docs/superpowers/specs/2026-11-10-tool-card-design.md`

## Global Constraints
- Don't touch `nx2/blocks/shared/card/*`, `nx2/blocks/shared/menu/*`, `nx2/scripts/nx.js`.
- Icon URL `${codeBase}/img/icons/s2-icon-<name>-20-n.svg#icon`, `<use width="100%" height="100%">`.
- Labels via `loc`: `Open`, `Learn more`, `Open in new tab`, `More options for`, `By Adobe`, `By Admin`.
- Events unchanged: `nx-cards-filter`, `nx-cards-ready`.

## Review Focus
- Card without `href` → no Open, menu only "Learn more" or no "…".
- `image` + `icon` both set → image wins.
- site-apps with `ref` mismatch → app skipped; no apps → section removed.
- Search hides `nx-action-card` in both blocks; empty query restores.
- Style guide renders the component (no console errors besides missing icons).
